打开 `http://localhost:4100/admin`（初始密码 `admin`，进 **设置 → 密码** 立刻改掉）。

## 编辑器

- 标题 + Markdown 正文，**Ctrl/Cmd + S** 直接保存发布
- 右侧栏：分类、标签、封面、精选开关、评论开关、slug
- 实时预览在下方，渲染管线和前台完全同一套

## 媒体库

拖拽即传，文件落在 `source/uploads/`。点"复制路径"直接粘贴进正文——

![示例封面](/uploads/demo-cover.svg)

## 命令行党

```bash
moonpress server            # 开发 + 热重载
moonpress new "文章标题"    # 用 scaffold/post.md 建文件
moonpress generate          # 导出静态站
```

两条路殊途同归：所有变更最终都是磁盘上的 Markdown。
