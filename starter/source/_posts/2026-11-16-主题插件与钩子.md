## 主题 = 目录

```
themes/我的主题/
├── theme.yml          # 名称/描述/作者
├── _config.yml        # 主题配置（前台以 theme.xxx 取用）
├── layout/            # layout.ejs 包裹 + index/post/page/archive(.ejs)
└── source/            # css/js/img → 站点根
```

模板里可用：`site`、`page`、`config`、`theme`，以及 `url_for` `date` `relative_date` 等助手。

## 插件 = 一个 JS 文件

放进站点 `plugins/`，导出一个函数：

```js
module.exports = (api) => {
  api.filter('post_init', post => { /* 改数据 */ return post; });
  api.filter('post_render', html => html.toUpperCase()); // 别真这么干
  api.action('server_start', (site, port) => console.log('起来了', port));
};
```

内置钩子：`post_init` `post_render` `page_render` `template_locals` `site_ready` `comment_posted` `server_start` `generate_end`。

引擎自带的 `reading-time`（阅读时间）与 `external-links`（外链安全）插件就是现成示范。
